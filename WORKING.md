# WORKING.md — How SmartCSV Analyst Works

A plain-English guide to every feature in the app.

---

## 1. Upload Page

**How to use it:**
- Click "Upload File" tab and drag-and-drop any CSV (or TSV/TXT with comma/semicolon/tab separators)
- Or paste a direct URL to a CSV file in the "Load from URL" tab
- Or click "Load Sample Data" to instantly load the built-in 303-row finance dataset

**What happens behind the scenes:**
1. The file bytes are MD5-hashed. If you upload the same file again, nothing is re-processed (cached).
2. `charset-normalizer` auto-detects the file encoding (UTF-8, Latin-1, CP1252, etc.)
3. The delimiter is sniffed from the first 4KB (comma, semicolon, tab, pipe)
4. Duplicate column names are auto-renamed with `_1`, `_2` suffixes
5. A `DatasetMetadata` object is stored in Streamlit session state for all pages to share

**Result:** You see row count, column count, file size, memory usage, encoding, delimiter, missing count, and a 20-row preview.

## 2. Overview Page

**What you see:**
- **6 KPI cards:** Rows, Columns, Missing %, Duplicates, Numeric cols, Categorical cols
- **Column Details (left panel):** For every column — missing count, unique count, and type-specific stats:
  - *Numeric columns:* mean, median, std, min, max, Q1, Q3, IQR, outlier count, plus a histogram
  - *Categorical columns:* most frequent value + a bar chart of top 10 values
  - *Datetime columns:* date range in days, most common day of week
- **Data Quality (right panel):** Warnings for high missing %, duplicates, constant columns, high-cardinality columns
- **Column Types pie chart:** How many numeric vs. categorical vs. datetime columns
- **Top 5 Correlations:** Strongest Pearson correlation pairs

**How profiling works:**
- When you land on the Overview page, `profiling.profile_dataset()` runs once.
- The result is cached in session state. If you go back and clean data, and the DataFrame shape changes, it re-profiles automatically.

## 3. Clean Page

Five tabs of data cleaning:

### Missing Values Tab
- See which columns have missing data
- **Drop Rows:** Remove every row that has a NaN in selected columns (or all columns)
- **Drop Columns:** Remove columns where the missing % meets your threshold (0–100%)
- **Fill Values:**
  - Numeric: fill with mean / median / zero
  - Categorical: fill with mode (most frequent)
  - Custom: type in your own value

### Duplicates Tab
- See the exact count of duplicate rows
- Choose which columns to consider for deduplication (or all)
- Choose to keep `first`, `last`, or drop all duplicates

### Type Conversion Tab
- Pick a column and convert it to: `int64`, `float64`, `string`, `datetime64`, `bool`, or `category`

### Filter Tab
- Pick a column and apply: `==`, `!=`, `>`, `<`, `>=`, `<=`, `between`, `contains`, `in`
- Rows not matching the filter are removed

### Derived Columns Tab
- Create a new column using an expression like `Revenue - Cost` or `Price * 1.1`
- **Security:** Expressions are evaluated with `asteval` in a restricted namespace — no access to Python builtins, file system, or imports

**All operations are recorded in the Audit Trail** (visible at the bottom of the page).

## 4. Visualize Page

**Sidebar controls:**
- Choose a **Chart Type** from: histogram, box plot, bar chart, scatter, line, grouped bar, scatter with color, scatter with size, faceted scatter, correlation heatmap, grouped box plot
- Choose **X Axis** and **Y Axis** columns (where applicable)
- Choose a **Color** column (optional)
- Customize the chart **title**
- For histogram: set the number of bins

**Click "Generate Chart"** → a Plotly interactive chart appears.

**Export:** Download as interactive HTML or static PNG.

**Performance note:** If your dataset has more than 50,000 rows, it is randomly sampled down before rendering so your browser doesn't freeze.

## 5. Insights Page

Automated insight cards are generated by analyzing your data:

| Insight Type | What It Detects |
|---|---|
| Missing Data | Columns with > 50% missing values |
| Quality | Constant columns, duplicate rows |
| Outliers | Columns with IQR-based outlier counts |
| Correlation | Column pairs with Pearson r >= 0.7 |
| Distribution | Columns with skewness magnitude > 2 |
| Trends | Numeric columns trending up/down over time |
| Cardinality | Columns with very high unique-value counts |

Each insight has:
- **Severity:** critical (red) / warning (yellow) / info (blue)
- **Category:** the type of issue
- **Explanation:** a plain-English description
- **Suggestion:** a recommended action

You can filter by category. Click "Export Insights Summary" to download as a text file.

---

## 6. Export Page

Four download options:

1. **Cleaned Dataset (CSV):** The current (possibly cleaned) DataFrame as a CSV file
2. **Audit Log (JSON):** Every cleaning operation you performed — action, column, method, rows affected
3. **Profile Report (TXT):** Human-readable summary of all column statistics
4. **Insights Summary (TXT):** All generated insight cards

---

## Session State Flow

```
Upload -> stores: df, original_df, metadata, file_hash, audit_trail
Overview -> stores: profile (cached by shape)
Insights -> stores: insights (cached until new upload)
Clean -> modifies: df, audit_trail
```

All pages read from `st.session_state`. If no file is uploaded, pages show a "please upload first" warning.

---

## Error Handling

- Every page is wrapped in a try/except in `app.py` — errors show a user-friendly message without crashing the app
- File ingestion errors show specific messages (file too large, encoding error, empty file, etc.)
- Chart generation errors show inline error messages
- All errors are also logged to stderr for debugging
